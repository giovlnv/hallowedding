# img/

Pasta reservada para fotos reais dos presentes, hospedadas localmente (sem serviço externo). Cada card em `presentes.html` reserva o espaço (`.imagem-placeholder`); quando houver uma foto para um item, adicione o arquivo aqui e troque a `div.imagem-placeholder` correspondente por `<img src="img/nome-do-arquivo.jpg" alt="...">` em `js/presentes.js`.
